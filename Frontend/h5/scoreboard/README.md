# 记分牌系统 Web 应用

这是一个现代化的 Web 记分牌应用程序，将原有的 Electron 桌面应用转换为了可在浏览器中运行的 Web 应用。

## 项目概述

记分牌系统是一个用于展示和控制比赛计分信息的应用程序。它最初是基于 Electron 的桌面端应用，现已成功转换为 Web 应用，可在任何现代浏览器中运行。

## 功能特性

- **实时比分显示** - 清晰展示主队和客队的实时比分
- **计时器控制** - 支持正计时和倒计时功能
- **主队/客队分数管理** - 独立管理两队的分数
- **队名和队徽自定义** - 可自定义队伍名称和上传队徽
- **多记分牌管理** - 支持创建和管理多个独立记分牌
- **键盘快捷键控制** - 支持丰富的键盘快捷键操作
- **自适应缩放** - 自动根据屏幕尺寸调整显示比例

## 键盘快捷键

- `H` / `I` - 主队加分
- `K` - 主队减分
- `G` / `O` - 客队加分
- `L` - 客队减分
- `T` - 启动/停止时钟
- `U` - 增加时间
- `J` - 减少时间
- `F` - 全屏切换
- `+` - 增大显示比例
- `-` - 缩小显示比例
- `0` - 自动缩放

## 多记分牌管理

系统支持创建多个独立的记分牌，每个记分牌都有自己的：
- 比分（主队和客队）
- 计时器（可独立运行/暂停）
- 队伍名称和队徽
- 显示缩放比例
- 可见性设置

## 技术栈

- **前端框架**: Vue 3
- **UI 框架**: Quasar Framework
- **状态管理**: Pinia
- **语言**: TypeScript
- **构建工具**: Vite

## 安装和运行

1. 克隆项目仓库
2. 安装依赖：
   ```bash
   pnpm install
   ```
3. 启动开发服务器：
   ```bash
   pnpm dev
   ```
4. 在浏览器中打开 `http://localhost:9000`

## 项目结构

```
src/
├── components/     # Vue 组件
├── layouts/        # 页面布局
```

## 使用说明

1. 在控制面板中创建新的记分牌
2. 设置主队和客队的名称
3. 设置初始分数和比赛时间
4. 通过记分牌页面查看实时比分和时间
5. 使用键盘快捷键快速调整比分和时间
6. 可通过队徽上传功能为队伍添加图标

## 从 Electron 到 Web 的转换

此项目成功将原有的 Electron 桌面应用转换为现代 Web 应用，保留了所有核心功能：

- 移除了所有 `window.electronAPI` 调用
- 将多个独立的 HTML 页面整合到单页应用中
- 使用基于路由的导航结构
- 实现了集中状态管理（Pinia）
- 保留了完整的键盘快捷键支持
- 实现了响应式设计
